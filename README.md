# Director's Choice Ltd

Static site for Director's Choice Ltd — a one-stop merchandise partner for
theme parks and IP owners.

No build step, no dependencies. The repository root is the document root.

Live at **https://www.letszum.com**

## Local preview

```
python3 -m http.server 4321
```

Then open http://localhost:4321

## Structure

```
index.html            all content
assets/css/style.css  design tokens and layout
assets/js/main.js     sticky nav, mobile menu, scroll reveal
assets/img/           photography — see README.txt there for slot names
```
